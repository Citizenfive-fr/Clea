Thème 03

Les bases légales

Tous vos traitements doivent reposer sur une base légale, appelée également base de licéité, pour être conformes. Autrement dit, il vous faut une justification légale qui vous accorde le droit de pouvoir réaliser cette action. Il existe 6 bases différentes :

Le consentement

L'exécution d'un contrat ou de mesures précontractuelles

L'obligation légale

La sauvegarde des intérêts vitaux de la personne

L'exécution d'une mission d'intérêt public ou relevant de l'exercice de l'autorité publique

L'intérêt légitime

En clair et pour faire simple

Pour une entreprise, dans la majeure partie des cas, les bases légales les plus utilisées sont : le contrat ou les mesures précontractuelles, l'intérêt légitime, l'obligation légale et le consentement. Toutes les bases ont la même valeur, aucune ne prévaut sur les autres. Vous pouvez donc choisir librement celle que vous souhaitez, à condition bien évidemment de respecter les conditions qui en découlent.

Attention quand même, dans certains cas vous n'avez pas le choix, la base est imposée. Exemple typique : les cookies publicitaires. Pour ceux-là, c'est obligatoirement le consentement, vous ne pouvez pas vous appuyer sur l'intérêt légitime.
